# COVIDash.it

COVIDash.it is served by the FastAPI + React application in this monorepo, with Prefect ETL loading PostgreSQL warehouse tables. The project is now an archival showcase: upstream public COVID-19 data is historical, while the repo demonstrates a modern full-stack analytics implementation.

- Product: [covidash.it](https://covidash.it)
- Source repository: [github.com/fabriziomiano/covidashit](https://github.com/fabriziomiano/covidashit)
- Architecture notes: [architecture.md](architecture.md)
- Showcase notes: [showcase.md](showcase.md)

See the repository README for current local run, Docker, API, ETL, and deployment instructions.
